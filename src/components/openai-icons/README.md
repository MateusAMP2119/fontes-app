All application UI icons must be imported through `src/components/icons.tsx`.
Add icons from this same upstream set when needed. Do not add another icon library or draw replacement UI glyphs.
Brand logos, publisher favicons, charts and canvas drawings are content, not UI icons.
The shared adapter supplies sizing and accessibility defaults without changing the paths.
